# Approved decisions

These decisions were confirmed after the original request and take precedence over conflicting provisional wording.

- Separate matching layouts for Complete Inspection and Dents & Tires.
- Exactly two main report pages: visual inspection summary and category-based condition overview.
- No dollar estimates. No visible AI-generation label in the PDF; unrelated application disclosures remain unchanged.
- Tread required at all four corners. Technicians must provide measured tread and pressure; self-inspectors may explicitly mark unavailable with a reason. Measured brake/battery tests remain optional.
- Every confirmed puncture or embedded foreign object requires replacement under the selected program policy, even when pressure is retained. This is not a claim that all punctures are universally technically irreparable.
- An unchecked-by-default "Include photo evidence appendix" option, when selected, generates a separate PDF with all findings and every uploaded inspection photo. No appendix page limit.
- Use the recommended US Letter portrait format, inspector certification, guided evidence review and bounded Jev classification integration detailed in the final handoff.

For exact definitions and acceptance criteria, use `docs/inspection-report-redesign/05-developer-handoff.md` and `06-field-map-and-rules.md`.
